# ADR-027 — Couple Match Score ownership

Status: Accepted for Prompt 007.

Couple Match Score is CoupleOutfit-owned deterministic ranking logic. Versioned local component rules and weights produce an integer 0–100 score; OpenAI provides no ranking judgment. Prices, affiliate incentives and brands do not affect fashion scores.

See [matching and ranking foundation](../architecture/matching-ranking-foundation.md) for the exact v1 rules and limitations.
